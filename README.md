# VALENCE CAPITAL — Autonomous Corporate Treasury & Financial OS

An Awwwards-tier, $150k-agency-grade Fintech / Neobank landing page inspired by the engineering precision of **Mercury**, **Stripe**, and **Ramp**.

Designed for modern venture-backed startups and high-growth engineering teams managing global operating cash, multi-bank FDIC insurance ($75M), automated 5.24% APY US Treasury yield, and programmable corporate cards.

---

## Key Features & Architecture

- **Interactive 3D Titanium Corporate Card**:
  - Realistic 3D perspective tilt following mouse physics (`rotateX`, `rotateY`, dynamic specular glare).
  - Material finish selector: **Obsidian Titanium**, **Brushed Platinum**, and **Raw Tungsten**.
  - Interactive flip controller revealing virtual CVV and routing details with haptic clipboard copy.
- **Autonomous Capital Ledger**:
  - Live simulated transaction stream featuring automated treasury yield compounding, vendor payouts, venture debt intake, and real-time category filtering.
  - Compounding APY yield counter that continuously increments.
- **Interactive Treasury Yield & FDIC Calculator**:
  - Draggable financial slider ($250K → $30M).
  - Real-time calculations of daily compounding interest, $75M FDIC multi-bank sweep coverage, and comparative gains over 0.01% legacy banks.
- **Asymmetric Bento Grid**:
  - Live foreign exchange (FX) converter with real mid-market rate calculation (USD, EUR, GBP, JPY, SGD).
  - Multi-entity subsidiary isolation architecture preview.
  - Programmable Developer API code snippet with 1-click copy.
- **Institutional Comparison Matrix**:
  - Feature-by-feature breakdown comparing Valence Capital against Mercury and traditional commercial banks.
- **Spring-Physics Single-Expand FAQ**:
  - Smooth animated height transitions for institutional inquiries.
- **Full SEO Suite**:
  - Schema.org `FinancialService` and `Organization` JSON-LD structured data.
  - Open Graph & Twitter Summary Cards with preconnect tags for Core Web Vitals.
- **100% Mobile Responsive**:
  - Tested from 320px screens to 4K displays with strict zero horizontal overflow constraints.
- **Zero Frameworks**:
  - Pure Semantic HTML5, Vanilla CSS (Double-Bezel concentric architecture), and Modular Vanilla JS.

## 🚀 Running Locally

Serve via any standard HTTP server:

```bash
# Python 3
python -m http.server 8081

# Or Node.js
npx serve .
```

Then visit `http://localhost:8081` in your browser.
